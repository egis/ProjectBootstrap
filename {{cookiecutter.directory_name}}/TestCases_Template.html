🧩 How to use this template

  • This is a reusable PaperTrail test-case template — you don't fill it in by hand.
  • Open your project in Claude Code (or paste this file to Claude) and ask:
  • "Create test cases for the <feature> using the TestCases_Template.html format."
  • Claude produces a finished doc in this style: Sample Data first, then one table per feature area, with a Pass/Fail dropdown on every row.
  • While testing, pick Pass/Fail per row, then click 💾 Save results to download your sign-off copy.

📖 How to read it
